# Downloads – DayMate 1.8

- **[DayMate.apk](DayMate.apk)**: almost every Android phone from 2017 onwards. Start with this one.
- **[DayMate-older-phones.apk](DayMate-older-phones.apk)**: only if the first one says it isn't compatible with your phone (older 32-bit phones).

Android 8.0 or newer. To install, open the file on your phone and allow installing from your browser or Files app if asked.
On first start, tap **Allow** so reminders can ring and show full screen.

Note: from 1.7, DayMate is signed with its permanent release key. Coming from 1.6 or older, uninstall the old app once first (its data is deleted, so note anything important).
